# gold-private — разметка ревью из истории своих проектов

Кейсы для `pr-review-gold` из истории репозиториев, где работает ревью: Orakul, Restate,
Iot_Gateway, cod-doc. **Кода здесь нет**: каждый кейс — только `meta.json` с пином
(`source.local` — имя клона, `source.base..source.sha` — дифф PR/MR), местами дефекта и
коммитами-фиксами. Дифф и дерево проекта на коммите кейса строятся из локального клона в
gitignored-кэш (`.ai-review/gold-public/`, `trees/`).

## Как собраны

`bin/pr-review-gold-harvest-local.mjs` — SZZ по локальной истории, без LLM:

1. единица — коммит первого родителя интеграционной ветки (merge PR/MR или squash);
2. фикс — единица с заголовком `fix…` или из ветки `fix/…`;
3. строки, удалённые фиксом, — `git blame` на родителе фикса → PR-виновник;
4. место дефекта в диффе виновника — по тексту удалённой строки среди добавленных им.

| Тип | Ожидание | Источник |
|---|---|---|
| `tp` | найти места дефекта (`mustFindLocations`); `wouldBlock` не задан — не каждый исправленный дефект major | PR, чьи строки потом исправил фикс |
| `tp` + тег `contract` | то же | фикс поменял вызов функции, объявленной в **одном** другом файле и импортированной из своего проекта — класс, на котором должны помогать карточки символов (RFC 14) |
| `clean` | `wouldBlock: false` | PR старше 45 дней, ни одна строка которого не попала под фикс |

Пороги — как у публичного набора (RFC 03): дифф виновника ≤ 800 строк и ≤ 15 файлов, фикс ≤ 150
удалённых строк, фикс не позже 120 дней после виновника; строки короче 12 символов, импорты и
тесты в разметку не идут.

**Ограничения разметки.** Clean — это «фиксов не было», а не «дефектов нет». TP — дефект, который
нашли и исправили; ревью, нашедшее другой реальный дефект в том же PR, оценщик посчитает
промахом по локациям, но не ошибкой. Набор — кандидаты сборщика; перед выводами по метрике
кейс стоит прочитать глазами.

## Запуск

```bash
export REVIEW_GOLD_REPOS="orakul=/path/Orakul,restate=/path/Restate,gateway=/path/GatewayDemo,coddoc=/path/cod-doc"
REVIEW_GOLD_DIR=gold-private OLLAMA_API_KEY=… node bin/pr-review-gold.mjs [--case <id>]
```

Раннер разворачивает дерево проекта на `source.sha` (`git archive`, клон не меняется) и гоняет
ревью из него — модель видит настоящие окна контекста. Граф для карточек символов берётся из
`.graphify/graphify-out/graph.json` внутри дерева, если его там построить; без графа карточек
нет. `REVIEW_GOLD_CHECKOUT=0` — прогон без дерева.

Пересобрать набор (перезапишет `meta.json` кандидатов):

```bash
node bin/pr-review-gold-harvest-local.mjs --repo /path/Orakul --name orakul --branch origin/main --since 2026-01-01 --emit gold-private
```
