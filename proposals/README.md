# Proposals (RFC)

Решение, которое дороже отката, фиксируется здесь **до** кода. Порог тот же, что в cod-doc:
RFC пишется, если идея трогает ≥ 2 модуля движка или меняет контракт с потребителем;
меньше — обычная задача. Реализация трекается не здесь: RFC не переезжает в «done».

Отклонённый RFC остаётся в каталоге с пометкой в таблице — это дешёвая защита от

## Формат

`proposals/NN-kebab-slug.md`, номер не переиспользуется. Первая строка после заголовка —
мета: `> Категория: … · Риск: … · Зависимости: …`.

| Поле | Значения |
|------|----------|
| Категория | 🎯 Прямое (ложится на существующую модель) · 🟡 Адаптация · 🔵 Архитектура (меняет границы) |
| Риск | низкий · средний · высокий |

Секции: **Контекст** → **Текущее состояние** (по коду, с `file:line`) → **Предложение**
(конкретика: сигнатуры, имена, пути) → **Миграция** → **Риски и что не делаем** → **Оценка**.

Секция «Текущее состояние» обязательна и проверяется по коду, а не по памяти: без неё RFC
предлагает то, что уже сделано.

## Готов к декомпозиции

- [ ] «Текущее состояние» сверено с кодом.
- [ ] Есть хотя бы один конкретный контракт (сигнатура, имя файла, правило теста).
- [ ] Non-goals выписаны.
- [ ] Оценка в задачах есть.
